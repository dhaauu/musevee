# MusEvee

Pemutar musik *hybrid* modern untuk Android yang menggabungkan koleksi lagu lokal (`MP3`, `FLAC`, `M4A`) dan *streaming online* bebas iklan dalam satu antrean yang sama — lengkap dengan lirik berjalan, konversi Romaji instan, kartu kutipan lirik (*Share Card* & *Story 9:16*), serta pembaruan langsung di dalam aplikasi.

## Cara Memasang di Android

1. Unduh file **`MusEvee-v1.0.0-arm64.apk`** dari halaman [Releases](https://github.com/hdkmjr12/musevee/releases/latest) atau langsung melalui [Website Resmi](https://hdkmjr12.github.io/musevee/#download).
2. Buka file APK dan izinkan **Pasang aplikasi tidak dikenal** (*Install unknown apps*) untuk browser atau file manager.
3. Jalankan MusEvee dan izinkan akses audio lokal untuk mulai memutar musik offline maupun online.

> Untuk pembaruan versi berikutnya, cukup buka **MusEvee → Tentang → Tentang aplikasi → Periksa pembaruan**, atau ketuk notifikasi pembaruan yang muncul otomatis di beranda aplikasi.
